# Como gerar o APK automaticamente pelo GitHub

1. Crie uma conta no GitHub em https://github.com/
2. Crie um novo repositório, por exemplo: `relogio-sempre-visivel`.
3. Envie todos os arquivos desta pasta para o repositório.
4. No GitHub, abra a aba **Actions**.
5. Clique em **Gerar APK**.
6. Clique em **Run workflow**.
7. Aguarde a compilação terminar.
8. Abra a execução concluída.
9. Em **Artifacts**, baixe `RelogioSempreVisivel-debug`.
10. Dentro do arquivo estará `app-debug.apk`.

Depois de instalar, abra o aplicativo e permita **Exibir sobre outros apps**.
Em seguida toque em **Ligar relógio**.
